# Documentation

The documentation follows [Diátaxis](https://diataxis.fr/): each page is either a tutorial, a how-to guide, reference or an explanation, and lives in the folder for its kind. Later tickets add pages, and list each one in its folder's README.

- [Tutorials](tutorials/README.md): lessons that take a newcomer from nothing to a working result.
- [How-to guides](how-to/README.md): steps for one task, for someone who already knows the repo.
- [Reference](reference/README.md): facts to look up, such as commands, file formats and configuration.
- [Explanation](explanation/README.md): background and reasoning, such as why the toolchain is shaped the way it is.

The [architecture decision records](adr/README.md) record each decision that shaped the repo, and the [glossary](../GLOSSARY.md) defines its vocabulary.
